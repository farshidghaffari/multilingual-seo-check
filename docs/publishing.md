# Development and publishing

Run `python -m unittest discover -s tests -v` before pushing changes. GitHub Actions runs offline tests across supported Python versions. Live checks are deliberately manual to avoid network-dependent CI.

For reproducible citations, include the repository URL, a commit SHA and tool version. Software citation metadata is in CITATION.cff.

The LinkedIn text in this directory is an unpublished draft. Verify the latest CI result and update any test counts before posting.
